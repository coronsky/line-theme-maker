# Mon Chein 着せかえ工房（line-theme-maker）

LINE着せかえの提出用画像62枚を、ブラウザだけで作る・確認する・ZIPにするツールです。`index.html` を開くだけで動きます（外部ライブラリなし）。

## できること
- キャラクター画像1枚と配色から、62枚すべてを自動生成（メイン3・メニュー36・メニュー背景1・パスコード16・プロフィール4・トーク背景2）
- スマホ画面のプレビュー（iOS 26未満／iOS 26以降のメニュー、バッジ位置、トークルームの見え方）
- 作成済みZIP・PNGの取り込み（ファイル名で自動振り分け、圧縮ZIP・フォルダ入りZIP・Shift_JIS名のZIPにも対応）
- ChatGPTで作った3×3のアイコン素材シートを切り出してメニューに配置（背景の自動透過、OFFの自動作成）
- 規定チェックと「直す」ボタン（サイズ、メイン画像の透過、トーク背景1MB、メニューの余白、iOS 26の白黒背景での見やすさ、ON/OFFの同一、申請テキストの文字数）
- 1枚ずつの差し替え・位置調整
- ZIP書き出し後に中身（枚数・ファイル名・CRC）を自動検証
- 途中保存と呼び出し（ブラウザ内に複数保存、Ctrl+S、自動保存からの再開、`.mctheme.json` ファイルへの書き出し・読み込み）

## 規定の出典
LINE Creators Market「制作ガイドライン（詳細）」（2026年10月に確認）。申請前に最新版を確認してください。

`legacy/` には以前の版を残しています。
